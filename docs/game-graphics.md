# 图形外设接口

## 选择与使用

```bash
make nvboard PROGRAM=mario
make nvboard PROGRAM=pvz
make nvboard PROGRAM=tetris
```

每次构建选择一个后端，共用 `vga_timing.v`。CPU 提交图块、精灵或字符地图，RTL 生成像素，不使用 CPU 全屏 RGB 帧缓冲。

| 游戏 | 后端 | 画面 |
| --- | --- | --- |
| Mario | `mario_video.v` | 256×240，2 倍放大后居中 |
| PvZ | `pvz_video.v` | 320×240，2 倍放大 |
| Tetris | `tile_video.v` | 40×30 格，每格 16×16 像素 |

板级参数默认选择 Mario；PvZ 使用 `PVZ_MODE=1`，Tetris 使用 `TETRIS_MODE=1`，不要同时启用。统一输出 640×480，扫描总周期为 800×525。

## 提交约定

画面状态写入后台缓冲，写提交寄存器后，在 VGA 帧边界交换前后台。提交寄存器读 bit0 为 pending；CPU 应等待它清零后再写下一帧。SoC 在等待读取期间暂停核心，VGA 继续运行。

以下均为相对基址 **`0x20000000`** 的偏移。静态字模与素材在启动时上传，每帧更新后台画面状态。

## Mario 图块与精灵

| 偏移 | 内容 |
| --- | --- |
| `0x0000–0x1fff` | 8 KiB CHR，512 个 8×8、2bpp 图块 |
| `0x2000–0x27ff` | 后台 nametable，2 KiB |
| `0x2800–0x28ff` | 后台 OAM，64 个精灵，每个 4 字节 |
| `0x2900–0x291f` | 32 个调色板索引 |
| `0x2a00–0x2a03` | ctrl、mask、scrollX、保留字节 |
| `0x2a04` | 提交 / pending |

素材为原始 CHR 编号与 2bpp 索引，不是任意图片拼接。精灵使用扫描线缓存，颜色经固定 NES 调色板转换成 RGB。操作及导入方法见[Mario](mario.md)。

## PvZ 索引背景与精灵

| 偏移 | 内容 |
| --- | --- |
| `0x00000–0x12bff` | 背景 0：单行草皮，320×240、8-bit 索引 |
| `0x20000–0x3ffff` | 精灵图集前 128 KiB |
| `0x40000–0x403ff` | 256 个 RGB888 调色板项，每项 4 字节 |
| `0x41000–0x413ff` | 后台 64 个精灵描述符，每个 16 字节 |
| `0x41400` | 写 1 提交 / 读 pending |
| `0x41404` | 待显示背景编号：0 单行、1 标题、2 菜单、3 三行 |
| `0x41408` | 有效精灵数 0–64，超出钳制到 64 |
| `0x60000–0x72bff` | 背景 1：标题 |
| `0x80000–0x92bff` | 背景 2：菜单 |
| `0xa0000–0xbffff` | 图集后 128 KiB，映射图集偏移 `0x20000` 起 |
| `0xc0000–0xd2bff` | 背景 3：三行草皮 |

描述符的四个 32 位字依次为：`xy`（低 16 位 x、高 16 位 y）、`texture`（bit31 使能、bits17:0 为图集偏移）、`size`（bits7:0 为宽、bits15:8 为高，其余保留）、保留字。坐标支持带符号裁剪，精灵颜色索引 0 表示透明。

背景编号和有效数量随提交切换。每条逻辑扫描线在消隐期合成，每周期最多处理 32 像素；第二条物理扫描线复用结果。仿真会检查扫描线合成期限。

## Tetris 字符与色块

| 偏移 | 内容 |
| --- | --- |
| `0x0000–0x12bf` | 后台 1200 格，每格占一个 32 位总线字，低 16 位有效 |
| `0x2000` | 提交 / pending |
| `0x3000–0x33ff` | 128 个字模，每字 8 行字节、每行低 5 位有效 |
| `0x3400–0x343f` | 16 个 RGB888 调色板项，每项 4 字节 |

格数据为：字符 bits7:0、前景色 bits11:8、背景色 bits15:12。5×7 字模放大两倍；字符 128 显示立体色块，129 显示空心落点。

## PvZ 鼠标与光标

点击与移动独立传递，主机只提供输入，不绘制 VGA 光标：

```text
SDL 点击 → 点击 FIFO → mouse_mmio → CPU 游戏逻辑
SDL 移动 → mouse_position → mouse_cursor → VGA RGB
```

| 接口 | 编码 |
| --- | --- |
| `0x30000020` 读 | bit31 有效、bit18 右键、bit17 左键、bits16:9 y、bits8:0 x |
| `0x30000024` 写 | 写 bit0=1 确认消费当前点击 |
| 顶层 `mouse_position[19:0]` | bit19 位于画面内、bits18:10 y、bits9:0 x |

点击坐标为 320×240 游戏坐标，连续位置为 640×480 VGA 坐标。点击在确认前保持稳定，valid/ready 提供反压；主机 FIFO 容量为 64，满时丢弃超额点击，窗口失焦清空旧队列。移动只更新最新位置，不挤占点击队列。

`mouse_cursor.v` 在帧边界锁存位置，叠加黑边暖黄色箭头；16×24 图案放大到 32×48，热点为左上角尖端，屏幕边缘自动裁剪。进入画面时隐藏系统光标，离开或失焦后恢复。该接口不是实体 PS/2/USB 鼠标控制器。

检查：`make mouse-test`、`make cursor-test`、`make cursor-integration-test`。

## 存储与性能边界

图形外设存储独立于 CPU 的 4 MiB RAM：Mario 使用 CHR 和双缓冲状态，PvZ 使用四张背景、256 KiB 图集和描述符缓冲，Tetris 使用 4,800 字节双缓冲地图及字模/调色板。

仿真每个 VGA 帧需执行 420,000 个像素周期。更改时间刻度不会提升实际求值吞吐；SDL GPU 显示也不等于 GPU 仿真 RTL。不要跳过 `nvboard_update()`，否则会丢失像素及输入时序。
